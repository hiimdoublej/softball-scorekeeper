# WPA 與手機記分頁

## 勝率與排名

重現現有估算時，載入隨附的 `scripts/wpa.js`，呼叫 `estimateWpa(按影片順序排列的全場打席, row => 該打席是否為我隊進攻)`。每筆提供 inning、outs、runners、runs、batter。兩隊名稱先統一；背號使用字串。回傳 plays 與輸入同序，ranked 依球員累積打擊 WPA 排序。

- 以實際進攻局序、當前分差和雙方剩餘出局數估算。模型假設兩隊實力相等，每三個剩餘出局平均得一分，以卜瓦松分布計算未來得分。現有每位跑者另以零、一、兩出局對應 55%、38%、20% 的機率得分。這是未經聯盟校準的估計，只使用壘上人數。
- 從同一打擊方角度，以打後勝率減打前勝率得到該打席 WPA。每場結束按實際勝負取 1 或 0，平手取 0.5。此版本以最後一筆為終局，只適合已確認結束的比賽。中途截斷的影片要先處理剩餘局數。得分未知使後續分差不確定時，保留空白並指出缺口。
- MVP 比較兩隊全部打者，按「球隊＋背號」累加正負 WPA，同分並列。未知背號可算單球 WPA，暫不歸戶。標示已歸戶的打席數；得分或身份未齊時，排名標為暫定。此排名標為「進攻 WPA」；預設顯示前十名，其餘可展開。
- 顯示例「我隊 增加 4.2% → 我隊 54.2%　對手 45.8%」。增幅是前後勝率的百分點差，受益者也可能是守方。右側固定我隊在前，顯示打後勝率，未終場時若四捨五入會顯示 100% 或 0%，使用 >99.9% 或 <0.1%。核對無變化、負 WPA、最後一球以及 特殊賽制連打兩局的邊界。

## 手機與 CSV

- 我隊比分與打席用球隊指定色。參考 MLB Gameday 的 play-by-play，依實際進攻順序分局。小記分板顯示打擊前兩隊當下比數、上／下局、出局燈與壘包菱形。有壘位證據才點亮對應的壘；只知道人數就標「壘位待確認」與人數。比分固定兩列，先攻在上、後攻在下，左欄隊名、右欄分數。得分打席另顯示同格式打後比數。從完整紀錄累計，再套篩選；前面有未知得分時將受影響隊伍標為待確認。保留讀屏文字。
- 判讀信心用滑桿，最右「全部打席」為預設，包含無評分與人工確認。選 90 顯示有影片結果分數且低於 90 的未確認打席。另可查看待確認清單。打席展開時預設開啟回看，使用者可關閉並保留偏好；無影片的打席略過播放器。
- 手動更正保留原依據，以穩定識別碼套用瀏覽器內儲存的修改。檢查插入打席、重新載入及改背號後的歸戶。篩選只影響顯示，比分、排名、CSV 皆以完整場次計算。
- 相容的 CSV 以 UTF-8 BOM、引號跳脫匯出。欄位依序為「打席、時間、攻方、結果、得分、判讀信心、狀態、原判讀依據、場次、局次、打席前壘上人數、打席前出局數、全場我隊得分、對手、全場對手得分、打者背號、攻方打前勝率、攻方打後勝率、打席進攻 WPA、本場打擊 MVP、勝率變化、打前我隊得分、打前對手得分、打後我隊得分、打後對手得分」。勝率數值欄使用 0 到 1，WPA 保留原精度計算排名，頁面使用帶正負號的一位小數百分比，CSV 打席 WPA 使用四位小數百分比。
- 更新既有 Sites 記分頁時，從該站目前發布的來源開始，保留識別碼及存取權。檢查每場首末打席、補記、重播、篩選、比分、MVP、匯出列數後，依 Sites 流程打包並確認部署成功。只有整理方法或離線分析的任務無需發布。
